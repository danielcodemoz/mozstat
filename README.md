# MozStat

Painel de indicadores **ao vivo** de Moçambique. Laboratório de Daniel Marcos (Maputo) — não é um produto de cliente nem um serviço oficial.

**Ao vivo:** https://danielcodemoz.github.io/mozstat/

Os números só aparecem se uma API os devolver. Nada é inventado. Se uma fonte falhar, o cartão mostra erro e um botão para tentar outra vez.

## O que mostra

- População, PIB, esperança de vida e área de superfície (Banco Mundial)
- Capital (Banco Mundial; REST Countries se a API pública responder)
- Línguas, moeda e bandeira **apenas** se o REST Countries as devolver
- Meteorologia actual em **Maputo, Beira, Nampula e Pemba** (Open-Meteo, sem chave)

## Fontes

- [Banco Mundial / World Development Indicators](https://data.worldbank.org/country/mozambique)
- [REST Countries](https://restcountries.com/)
- [Open-Meteo](https://open-meteo.com/)
